# Animatch - Find Your Next Favorite Anime

A modern, interactive anime recommendation platform that helps users discover anime based on their preferences. Built with vanilla HTML, CSS, and JavaScript.

## Features

- **Personalized Recommendations** - Add anime you've watched, rate them, and get tailored suggestions
- **Genre Discovery** - Browse 10+ anime genres with interactive category cards
- **My List** - Build your personal anime library with star ratings and favorites
- **Smart Matching** - Recommendation engine explains why you'll like each suggestion
- **Trending Section** - See what's popular in the anime community
- **User Profile** - Track your progress with XP, levels, and genre breakdowns
- **Community Picks** - Read what other anime fans are enjoying
- **Dark/Light Mode** - Toggle between themes for comfortable viewing
- **Gamification** - Earn achievements as you explore and rate anime
- **Fully Responsive** - Works on desktop, tablet, and mobile

## Tech Stack

- HTML5
- CSS3 (Custom properties, Grid, Flexbox, animations)
- Vanilla JavaScript (ES6+)
- No external dependencies or frameworks
- LocalStorage for data persistence

## Getting Started

Simply open `index.html` in a browser, or visit the GitHub Pages deployment.
